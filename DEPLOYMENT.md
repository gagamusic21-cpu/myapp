# Deployment Guide — Hawassa University Exams & Courses

Full-stack setup: **React + Vite frontend (Vercel)** ↔ **Express + Prisma + PostgreSQL API (Render)** ↔ **Neon / Supabase Postgres (free tier)**.

```
┌─────────────┐   HTTPS (CORS)   ┌──────────────┐   Prisma   ┌──────────────┐
│  Vercel     │ ───────────────▶ │  Render      │ ─────────▶ │  Neon /      │
│  (frontend) │  VITE_API_URL    │  (huec-api)  │ DATABASE_URL│  Supabase PG │
└─────────────┘                  └──────────────┘            └──────────────┘
```

**Default staff login after deploy: `admin` / `staff123`** (role `OWNER`) — change it via `.env` or delete & reseed.

---

## 1 · Run the full app locally

### 1a. Create the database (free)

**Option A — Neon:** sign up at neon.tech → create project → copy the **pooled connection string**
(`postgresql://user:pass@ep-….neon.tech/dbname?sslmode=require`).

**Option B — Supabase:** create project → Settings → Database → copy the **connection string**
(use the *Transaction pooler* string and append `&pgbouncer=true`).

### 1b. Backend

```bash
cd server
cp .env.example .env
# edit .env → set DATABASE_URL and a long random JWT_SECRET
#   generate one with:  node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

npm install
npx prisma db push     # creates all tables in your database
npm run seed           # creates the staff account (admin / staff123)
npm run dev            # API runs at http://localhost:4000
```

Verify: open http://localhost:4000/api/health → `{"ok":true,...}`.

### 1c. Frontend (second terminal)

```bash
# from the repo root
cp .env.example .env          # VITE_API_URL=http://localhost:4000 (already the default)
npm install
npm run dev                   # site runs at http://localhost:5173
```

Open http://localhost:5173 → **Staff dashboard** (top-right menu) → sign in with `admin / staff123`.
The dashboard chip should read **“Cloud · admin”**. Publish an exam → reload the page → it loads from the database.

## 3 · Deploy the backend to Render

1. Go to render.com → sign in with GitHub → **New → Blueprint** → select your repo.
   Render finds `server/render.yaml` and pre-fills a Node web service:
   - **Root Directory:** `server`
   - **Build command:** `npm install && npx prisma generate && npx prisma db push`
   - **Start command:** `node src/index.js`
2. It will pause for the `sync: false` env vars — set them in the dashboard:

   | Variable        | Value                                                            |
   | --------------- | ---------------------------------------------------------------- |
   | `DATABASE_URL`  | your Neon/Supabase connection string                             |
   | `CLIENT_ORIGIN` | *(set after step 4 — your Vercel URL, e.g. `https://huec.vercel.app`)* |
   | `STAFF_KEY`     | optional secret that lets signups create STAFF accounts          |

   (`JWT_SECRET` is auto-generated by the blueprint.)
3. Click **Apply** → Render installs, generates the Prisma client, pushes the schema, and boots.
4. **Seed the staff account once** — in the Render dashboard open your service → **Shell** tab → run:

   ```bash
   npm run seed
   ```

5. Verify: `https://huec-api.onrender.com/api/health` returns `{"ok":true,...}`
   *(copy your real URL from the Render dashboard — you need it next).*

> Free-tier note: Render free instances sleep after ~15 min idle; the first request after a pause takes a few seconds. The frontend waits for the API and falls back to local mode if it never answers, so visitors never see a broken page.

## 4 · Deploy the frontend to Vercel

1. vercel.com → **Add New → Project** → import the same GitHub repo.
2. Vercel auto-detects Vite (root of repo). Build: `npm run build`, output: `dist`.
3. **Environment variables** (Settings → Environment Variables):

   | Variable      | Value                                    |
   | ------------- | ---------------------------------------- |
   | `VITE_API_URL`| `https://huec-api.onrender.com` (your Render URL, no trailing slash) |

4. **Deploy**. When it finishes, copy the site URL (e.g. `https://huec.vercel.app`).
5. **Finish CORS wiring:** back in Render → your API service → Environment → set
   `CLIENT_ORIGIN=https://huec.vercel.app` (comma-separate several origins if needed) → **Save** (triggers a redeploy).

## Where things live

| Concern               | Location                                    |
| --------------------- | ------------------------------------------- |
| Frontend (your UI)    | `src/` — unchanged; talks to the API via `src/lib/api.ts` |
| API client + JWT      | `src/lib/api.ts` (`VITE_API_URL`)           |
| Express server        | `server/src/`                               |
| DB schema / models    | `server/prisma/schema.prisma`               |
| API documentation     | `server/README.md`                          |
| Seed script           | `server/src/seed.js`                        |
| Render blueprint      | `server/render.yaml` + `server/Procfile`    |
| Vercel config         | `vercel.json`                               |

**Graceful offline mode:** if `VITE_API_URL` is empty or the API is unreachable, the frontend automatically runs in *local device mode* (browser storage) so the static site is never broken.
